# Дифференциальное доказательство: оригинал против патча

Чтобы заявить, что фикс работает, покажи оригинал падающим и патч проходящим на
**одинаковом входе, в одном процессе**. Два отдельных прогона в разное время впитывают
дрейф окружения и ничего не доказывают.

## Форма

```python
def load(root, tag):
    """Импорт модуля из конкретного каталога с изолированными путями."""
    for name in list(sys.modules):
        if name == "target_module":
            del sys.modules[name]          # форсируем реальный ре-импорт
    sys.path.insert(0, root)
    mod = importlib.import_module("target_module")
    tmp = pathlib.Path(tempfile.mkdtemp(prefix=f"{tag}_"))
    mod.DATA_PATH = tmp / "data.json"      # никогда не трогаем реальное хранилище
    return mod

for tag, root, label in [("BEFORE", "path/to/original", "оригинал"),
                         ("AFTER",  "path/to/patched",  "после фиксов")]:
    mod = load(root, tag)
    mod.DATA_PATH.write_text(INPUT, encoding="utf-8")
    try:
        mod.some_operation()
        print(f"[{tag}] без ошибки; результат теперь: ...")
    except Exception as exc:
        print(f"[{tag}] отказ: {type(exc).__name__}")
```

Печатай таблицу сравнения. Человек читает таблицу, а не твою прозу.

## Самый ценный вход: испорченное состояние

Самый вредный агентский дефект — тихое разрушение хранимых данных. Воспроизведи намеренно
обрезанным/битым входным файлом:

```python
BROKEN = '{\n  "accounts": {\n    "user": {"password": "SECRET-1"}\n  },\n  "service": {"api_key": "SECRET-2"'
```

Затем проверяй содержимое файла после операции, а не только отсутствие исключения:

```python
after = mod.DATA_PATH.read_text(encoding="utf-8")
lost = ("SECRET-1" not in after) and ("SECRET-2" not in after)
print("СЕКРЕТЫ УНИЧТОЖЕНЫ" if lost else "секреты целы")
```

Форма результата, которая закрывает спор сразу:

| Код | Итог |
|---|---|
| оригинал | вызов «успешен», файл заменён пустым каркасом — **секреты уничтожены** |
| патч | `DataFileError: file corrupt (line 5, col 37)` — **файл нетронут** |

«Вызов успешен» ≠ «данные выжили». Всегда проверяй артефакт.

## Доказательство конкурентности без валидных часов

Сравнивать `time.monotonic()` между процессами бессмысленно — у каждого своя точка отсчёта.
Не строй аргумент на перекрытии интервалов.

Используй **неатомарный счётчик внутри критической секции**. Любой конкурентный вход теряет
обновления, поэтому сам счётчик и есть вердикт, вне зависимости от тайминга:

```python
with module._locked():
    val = int(COUNTER.read_text() or "0")
    COUNTER.write_text(str(val + 1))     # неатомарно намеренно
```

N процессов × R раундов обязаны дать ровно N*R. Меньше — взаимное исключение провалилось.
Ни часов, ни разбора логов не нужно.

## Логи на процесс, не общий лог

Дописывания в один общий лог не упорядочены между процессами. Если логируешь — дай каждому
процессу свой файл и коррелируй по PID.

## Храни доказательства

Пиши каждое доказательство скриптом в каталоге черновиков вне репозитория и перечисли их
в отчёте с тем, что каждое показывает. Это и есть доказательства, которые «покупает» человек.
Не коммить их в аудитируемый репозиторий — репозиторий получает тесты, каталог черновиков —
доказательства.
