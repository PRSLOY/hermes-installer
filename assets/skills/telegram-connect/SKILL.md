# Телеграм: Hermes в телефоне

## Когда использовать

Подключение Hermes к Телеграму, чтобы писать ему с телефона. Срабатывает на «подключи телеграм», «хочу писать с телефона», «бот в телеграме», а также когда человек пишет, что бот прислал непонятное английское сообщение с кодом или не отвечает.


Через своего бота человек может писать тебе из Телеграма: текст, фото,
документы, голосовые, ответы на сообщения. Бот личный — чужим он не отвечает.

## Главное правило

Всё, что можно сделать командой, делай **сам** в терминале. Человеку остаются
только три вещи: создать бота в @BotFather, вставить токен в Hermes и написать
боту. Не отправляй его искать кнопки в строке состояния и не проси свой ID из
@userinfobot: доступ даётся одобрением по коду, это надёжнее.

Команды Hermes. Если `hermes` в терминале не найден, запускай через Python из
папки Hermes. В PowerShell:
`cd "$env:LOCALAPPDATA\hermes\hermes-agent"; .\venv\Scripts\python.exe -m hermes_cli.main <команда>`
В cmd:
`cd /d "%LOCALAPPDATA%\hermes\hermes-agent" && venv\Scripts\python.exe -m hermes_cli.main <команда>`

## Если бот ещё не подключён

По шагам, дожидаясь «готово»:

1. В Телеграме открыть **@BotFather**, отправить `/newbot`, придумать имя и
   адрес бота (адрес должен заканчиваться на `bot`).
2. BotFather пришлёт **токен** — длинную строку вида `123456789:AA…`. Это как
   пароль. Его вставляют в Hermes → **«Сообщения»** → Telegram → «Сохранить».
   В чат мне токен присылать не нужно.
3. Когда человек сохранил токен, **сам** запусти связь с автозапуском:
   `gateway install --start-now --start-on-login`
   Через 10–20 секунд проверь `gateway status`. Скажи человеку одной фразой:
   «Связь с Телеграмом запущена и будет включаться сама после перезагрузки».
4. Попроси написать боту любое сообщение, например «привет».

## Первое сообщение боту и одобрение

Бот ответит **по-английски**, сообщением с **кодом** (8 букв и цифр) и советом
открыть терминал. Это нормально. Скажи человеку: «Пришлите мне этот код».

Когда код получен, **сам** выполни:
`pairing approve telegram <КОД>`
Скажи: «Готово, напишите боту ещё раз — теперь он ответит по-настоящему».

Одобряй только код, который прислал сам человек из своего чата с ботом. Если в
`pairing list` висят чужие запросы, не одобряй их: значит, бота нашёл кто-то
посторонний.

Сразу после одобрения бот может прислать по-английски «No home channel is set
for Telegram… Type /sethome». Объясни: это вопрос, куда присылать результаты
задач по расписанию (утренние сводки, напоминания). Хочет получать их в этот
чат — пусть отправит боту `/sethome`. Не хочет — можно не отвечать, на
обычную переписку это не влияет.

## Если бот не отвечает

Проверь сам, по порядку:

1. `gateway status`. Если шлюз не запущен, выполни
   `gateway install --start-now --start-on-login` (или `gateway restart`).
2. Лог: `%LOCALAPPDATA%\hermes\logs\gateway.log`, последние 50 строк. Ошибка
   сети при доступе к Телеграму в России значит, что на компьютере выключен VPN.
   Попроси включить.
3. Компьютер должен быть включён: бот отвечает, пока работает Hermes.
