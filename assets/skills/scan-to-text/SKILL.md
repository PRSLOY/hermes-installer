# Текст из сканов и фото документов

Задача — получить из скана или фотографии текст, которому можно доверять, и
честно показать, где распознавание могло ошибиться. Для остальной работы с PDF
(создать, склеить, разрезать, заполнить форму, поставить штамп) есть
встроенный скилл `pdf`: его и используй, этот скилл туда не лезет.

## When to Use — когда брать этот скилл

Просят распознать скан; вытащить текст из фотографии договора, чека,
паспорта, счёта, акта; PDF открылся, а текста в нём почти нет; звучат слова
«распознай», «OCR», «перепечатай с фото», «скан не читается».

**Когда не брать:** создать, склеить, разрезать, подписать,
заполнить PDF — скилл `pdf`; Word и Excel — `docx`, `xlsx`; правка текста
внутри PDF — см. раздел в конце.

Подстраивайся под человека: кто пишет технично — дай команды и цифры коротко;
кто нет — без терминов, одним следующим шагом.

## Главное правило: документы человека — его личные данные

Сканы — это паспорта, договоры, справки. Без явного согласия не отправляй их
ни в какие внешние сервисы: ни в поиск/`web_extract`, ни в режим `--use_llm`
у marker, ни в облачные редакторы PDF. Всё, что описано ниже, работает на
компьютере человека. Если модель, с которой ты сейчас работаешь, облачная, то
и просмотр картинки (`vision_analyze`) отправляет её этой модели — скажи об
этом одной фразой, если документ явно чувствительный (паспорт, медицинская
справка), и спроси, можно ли.

## Шаг 1. Сначала попробуй прочитать как есть

Открой файл через `read_file`. Если текст пришёл нормальный — задача решена,
ничего ставить не надо.

Признаки, что перед тобой скан: текста почти нет, есть только заголовки,
или в ответе есть предупреждение `EXTRACTION COVERAGE WARNING`. Не полагайся
только на предупреждение: оно появляется, лишь когда в системе есть программа
`pdftotext`, а её может не быть. Если сомневаешься — проверь по страницам
(шаг 3, ключ `--check`).

## Шаг 2. Фото или пара страниц — посмотри глазами

Если это фотография (jpg, png) или скан на 1–5 страниц и у тебя есть
`vision_analyze` — просто посмотри на картинку и перепечатай текст. Для фото
ничего устанавливать не нужно. Для страниц PDF сначала сохрани их картинками
(`--render`, шаг 3).

Больше 5–10 страниц так делать не стоит: долго и дорого. Тогда — шаг 3.

## Шаг 3. Распознавание на компьютере (нужна установка, только с согласия)

Нужно две вещи, обе без прав администратора и без отдельных окон:

- библиотека PyMuPDF (около 20 МБ) в отдельной папке, чтобы не трогать
  сам Hermes;
- файлы языков для распознавания: русский и английский, около 8 МБ.

Спроси человека одной фразой, например: «Чтобы распознать скан, мне нужно
скачать модуль для работы с PDF и словари русского и английского, всего около
30 МБ, в папку Hermes. Скачать?» Без «да» ничего не ставь.

После согласия (команды для терминала Hermes; `H` — папка Hermes):

```bash
H="${HERMES_HOME:-$LOCALAPPDATA/hermes}"
"$H/bin/uv.exe" venv "$H/doc-tools/venv" --python 3.11
"$H/bin/uv.exe" pip install --python "$H/doc-tools/venv/Scripts/python.exe" pymupdf
mkdir -p "$H/doc-tools/tessdata"
for l in rus eng; do
  curl -L --fail -o "$H/doc-tools/tessdata/$l.traineddata" \
    "https://github.com/tesseract-ocr/tessdata_fast/raw/main/$l.traineddata"
done
```

На Linux и macOS путь к Python в папке — `venv/bin/python`, а `uv` —
тот, что стоит в системе. Если чего-то из этого нет (например, нет `uv.exe`
в папке Hermes), не выдумывай замену — скажи человеку, чего не хватает.

Дальше — скрипт этого скилла (`PY` и `S` — короткие имена для путей):

```bash
PY="$H/doc-tools/venv/Scripts/python.exe"
S="$H/skills/scan-to-text/scripts/scan_to_text.py"
"$PY" "$S" "файл.pdf" --check                # на каких страницах нет текста
"$PY" "$S" "файл.pdf" --out "файл.txt"       # текст + OCR пустых страниц
"$PY" "$S" "фото.jpg" --out "фото.txt"       # фото документа
"$PY" "$S" "файл.pdf" --pages 2-3 --render "страницы"   # PNG для просмотра
```

- По умолчанию языки `rus+eng`. Другой язык — ключ `--lang` и файл
  `<код>.traineddata` из того же репозитория (например, `ukr`, `deu`).
- Результат сохраняй рядом с исходником только с новым именем. Оригинал
  скрипт никогда не меняет.
- В конце скрипт печатает сводку: какие страницы распознаны и какие
  остались пустыми. Пустые после OCR — скажи о них прямо, не пропускай молча.

## Шаг 4. Проверь результат, прежде чем отдать

OCR ошибается предсказуемо: путает `0` и `О`, `3` и `З`, `1` и `l`, теряет
пробелы в номерах и суммах. Поэтому:

- суммы, даты, номера договоров, ИНН, паспортные данные сверь с картинкой
  страницы (`--render` + `vision_analyze`, если он есть) или прямо попроси
  человека сверить эти поля;
- помечай места, в которых не уверен, а не угадывай их;
- при плохом качестве (размыто, под углом) скажи честно и попроси
  переснять ровно, при хорошем освещении — это часто быстрее любой настройки.

## Тяжёлый вариант: marker-pdf

Если нужно точно сохранить сложные таблицы, формулы, многоколоночную вёрстку
на десятках страниц, есть marker-pdf. Он тяжёлый: PyTorch и модели,
по словам его авторов, несколько гигабайт на диске и заметно дольше на
обычном процессоре. Предлагай его только когда простой путь не справился, и
только с согласием, назвав размер. Для организаций: по лицензии его моделей
бесплатное использование ограничено (личное, исследования, небольшие
компании) — если человек спрашивает для работы, скажи об этом и дай ему
самому проверить условия на странице проекта.

## Если просят исправить текст внутри PDF

Этот скилл текст не правит. Честный порядок:

1. Если есть исходник (Word, Excel) — правь его и сохрани PDF заново.
2. Штамп, подпись, заполнение формы — скилл `pdf`.
3. Не предлагай «ИИ-редакторы» PDF для договоров и счетов: некоторые из них
   перерисовывают страницу картинкой через облачную модель и могут незаметно
   изменить цифры рядом с правкой, а сам документ уходит на чужой сервер.

## Чего не делать

- Не ставить ничего «заранее» и без согласия.
- Не отправлять документы наружу без спроса.
- Не выдавать распознанный текст за точную копию: всегда говори, что проверил,
  а что стоит перепроверить глазами.
