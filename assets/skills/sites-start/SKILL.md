# Первый сайт

## Когда использовать

Сайт с нуля: визитка, лендинг, портфолио, страница для бизнеса. Срабатывает на «сделай сайт», «хочу лендинг», «сайт для моего магазина/кафе/услуг», «вайбкодинг». Не срабатывает на вопросы про чужие сайты.


Подстройся под человека: одному нужен готовый сайт без погружения в технологии,
другой хочет выбрать стек и разбираться в коде. В любом случае через полчаса
у него должна быть страница, которую он видит у себя в браузере.

## Порядок работы

1. **Расспроси коротко, по одному вопросу:** для чего сайт, кто его увидит,
   какие 3–5 блоков нужны (о себе, услуги, цены, контакты…), есть ли тексты и
   фото, какой настрой (строгий, яркий, уютный).
2. **Начни с одного файла.** Первая версия — один `index.html` со стилями
   внутри, без сборщиков и фреймворков. Открой его в браузере и покажи.
   Node.js и Git уже установлены вместе с Hermes — они понадобятся позже, если
   сайт вырастет.
3. **Правь по просьбам.** Человек говорит «сделай кнопку заметнее» — ты
   меняешь и снова показываешь. Каждый раз — готовый результат, не план.
4. **Выкладка в интернет — только когда попросит.** Объясни простыми словами
   варианты (бесплатный хостинг статических сайтов) и сделай вместе с ним.
   Никаких оплат и регистраций без его явного согласия.

## Качество

- Сайт обязан нормально выглядеть на телефоне — проверяй узкую ширину.
- Никаких выдуманных фактов о бизнесе человека: цены, адреса, отзывы — только
  те, что он дал. Где данных нет — оставь заметную пометку «заполните».
- Говори «готово» только после того, как открыл страницу и убедился, что всё
  на месте.

## Как говорить

С тем, кто не в теме, — без слов «вёрстка», «компонент», «деплой»: вместо кода
в ответе — что поменялось и куда посмотреть. С разработчиком — его языком.
