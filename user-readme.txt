Hermes — установка для подписчиков
==================================

Что делать (по шагам):
  1. Запустите HermesSetup.exe (или «Как установить.cmd») двойным кликом.
  2. Выберите провайдера на карточке (GWarden выделен) и нажмите «Далее».
  3. Вставьте API-ключ кнопкой «Вставить» (взять его — кнопкой «Получить ключ»).
  4. Нажмите «Установить», дождитесь результата и нажмите «Открыть Hermes».

Где взять ключ: в установщике нажмите «Получить ключ» на карточке провайдера.

Установка скачивает официальный Hermes Desktop и может занять 10–20 минут.
Нужен интернет и около 3 ГБ свободного места. Система должна быть
64-разрядной Windows 10 или 11.

Если Windows покажет СИНЕЕ окно «Windows защитила ваш компьютер» (SmartScreen),
это ожидаемо для программы без платной цифровой подписи:
нажмите «Подробнее» → «Выполнить в любом случае».

Если появилась ошибка:
  под кнопкой будет понятный текст — что именно проверить и что сделать
  (ключ, баланс/лимит, интернет или адрес API). Прочитайте его и повторите.
  Если не помогло — сохраните текст ошибки и передайте в поддержку.

Безопасность:
  ключ отправляется ТОЛЬКО по указанному вами HTTPS-адресу API и сохраняется
  локально в защищённом файле настроек Hermes. В журнал установки ключ не пишется.
  Для вычислений, справки и поиска в интернете Hermes обращается к внешним
  сервисам (Wolfram, Microsoft Learn, Context7, DeepWiki, поиск Exa/Parallel):
  туда уходит текст вашего запроса, но не ваш ключ.

Повторный запуск безопасен: установщик не удаляет существующие данные и не
перезаписывает чужие настройки.
