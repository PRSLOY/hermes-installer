# Hermes: установщик с готовым набором

Установщик для Windows, который ставит [Hermes Agent](https://github.com/NousResearch/hermes-agent)
(Nous Research) и сразу настраивает его под русскоязычного пользователя. От вас
нужен только ключ провайдера.

## Что получаете после установки

- **Hermes Desktop**, проверенный живым запросом к вашему провайдеру.
- **Честный помощник.** Личность (SOUL), которая не выдумывает факты,
  проверяет свежие данные и объясняет простыми словами.
- **Поиск и справочники без ключей:** Wolfram (математика), Microsoft Learn,
  Context7 (документация библиотек), DeepWiki.
- **Поиск товаров и цен:** Ozon, Wildberries, Авито, Яндекс Маркет, Детский мир
  (см. [известные проблемы](docs/KNOWN-ISSUES.md)).
- **Телеграм-бот** с полным Hermes в телефоне: текст, фото, голосовые на
  русском, пересланные сообщения. Подключается в установщике или позже, фразой
  «подключи телеграм».
- **Скиллы:** первые шаги, геймдев (Godot, Blender), сайты, проверка фактов,
  премортем, аудит безопасности и качества кода, покупка и ремонт авто,
  распознавание сканов и другие.

## Зачем это

Голый Hermes ставится через терминал, настраивается на английском, и на чистой
Windows в России у него тихо ломается половина: голос распознаётся
по-английски или не работает вовсе, часть сервисов «не на связи», задачи
обрываются посреди дела. Этот установщик всё это уже починил и проверил. Ты
вставляешь ключ, а через 15 минут у тебя свой ИИ-агент на компьютере и в
Телеграме.

## Как установить

1. Скачайте архив из [Releases](../../releases) и распакуйте.
2. Запустите `HermesSetup.exe`.
3. Выберите провайдера и нажмите «Получить ключ». Подсказки есть прямо в окне,
   для Dahl есть [пошаговый гайд с картинками](docs/dahl-key.md).
4. Вставьте ключ и нажмите «Установить». Установка занимает 10–20 минут.
5. Нажмите «Открыть Hermes» и напишите «Привет! Что ты умеешь?».

Если вы в России, держите VPN включённым: Telegram и часть провайдеров без него
недоступны. Поиск по маркетплейсам сам идёт мимо VPN.

## Провайдеры в установщике

| Провайдер | Модель | Бесплатно |
|---|---|---|
| GWarden | glm-5.3 | 7 дней |
| Dahl | MiniMax-M2.7 | 100 млн токенов |
| Atria | Atria-Dawn-Preview | 100 млн токенов |
| Inception | mercury-2.5 | бесплатные токены при регистрации |
| Другой | любой OpenAI-совместимый API | — |

Ссылка GWarden в установщике реферальная.

## Безопасность

- Ключ хранится только у вас на компьютере в защищённом файле Hermes. В логи
  и отчёты он не попадает.
- Телеграм-бот отвечает только тем, кого вы одобрили.
- Установщик не отключает защиту Windows. Права администратора Windows
  спрашивает, только когда без них никак. Например, для компонента Microsoft
  Visual C++, который нужен для распознавания голоса. Этот файл скачивается с
  сайта Microsoft, и перед запуском проверяется его подпись.

## Сборка из исходников

Нужны Windows 10/11 и .NET Framework 4.8 (компилятор `csc` уже есть в системе).

```powershell
powershell -ExecutionPolicy Bypass -File .\package-dist.ps1   # собирает dist\
```

Тесты:

```powershell
python -m pytest tests\backend -q      # нужен Python 3.12 с pytest и pyyaml
powershell -File tests\ui\run.ps1      # тесты интерфейса; запускать в Windows Sandbox
```
